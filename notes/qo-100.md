# QO-100 (Es'hail-2) hızlı başvuru

Yer eşlemeli uydu, konum **25,5° D**. Uplink 13 cm (2,4 GHz), downlink 3 cm (10,4 GHz).

## Dar bant (NB) transponder

| | Başlangıç | Bitiş |
|---|---|---|
| Uplink | 2400,050 MHz | 2400,300 MHz |
| Downlink | 10489,550 MHz | 10489,800 MHz |

- Alt işaret (CW): 10489,550 MHz
- Üst işaret (PSK): 10489,800 MHz

## Geniş bant (WB, DATV) transponder

| | Başlangıç | Bitiş |
|---|---|---|
| Uplink | 2401,500 MHz | 2409,500 MHz |
| Downlink | 10491,000 MHz | 10499,000 MHz |

- DVB-S2 işaret: 10491,500 MHz, 1,5 MS/s

## Frekans dönüşümü

```
downlink = uplink + 8089,5 MHz
```

Standart 9750 MHz LNB ile NB işaret IF'i yaklaşık **739,55 MHz** olur
(LNB ofsetine göre birkaç kHz kayabilir; işaret üzerinden kalibre et).
