# Sık kullanılan Q kodları

Soru olarak kullanıldığında sonuna `?` eklenir.

| Kod | Anlam |
|---|---|
| QRA | İstasyonunuzun adı |
| QRG | Tam frekansınız |
| QRL | Frekans meşgul |
| QRM | İnsan kaynaklı girişim |
| QRN | Atmosferik parazit |
| QRO | Gücü artır |
| QRP | Gücü azalt / düşük güç |
| QRS | Daha yavaş gönder |
| QRT | Yayını kes / kapanıyorum |
| QRV | Hazırım |
| QRX | Bekle |
| QRZ | Beni kim çağırıyor? |
| QSB | Sinyal dalgalanıyor (fading) |
| QSL | Alındı onayı / QSL kartı |
| QSO | Bağlantı / görüşme |
| QSY | Frekans değiştir |
| QTH | Konum |
